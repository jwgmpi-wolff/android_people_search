# Roadmap

## Extension criteria

The current `1.0.0` scope is complete. Future proposals may include locale-aware on-device name parsing, additional verified official county adapters, or broader accessibility coverage. Each proposal requires provider-policy review, focused tests, and documentation updates before implementation.

## Guardrails

Future work must preserve no-paid-source, no-secret, no-account-scraping, no-private-data, opt-in-history, source-attribution, and deterministic on-device assistant requirements.
